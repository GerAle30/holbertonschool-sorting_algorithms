# holbertonschool-sorting_algorithms

# Sorting algorithms & Big O

## 📚 Descripción

Este proyecto tiene como objetivo implementar al menos **cuatro algoritmos de ordenamiento diferentes**, comprender sus complejidades computacionales mediante la **notación Big O**, y aprender a elegir el algoritmo más eficiente según el tipo y tamaño de los datos. También se profundiza en el concepto de **algoritmos de ordenamiento estables**.

---

## ✅ Objetivos del proyecto

- Implementar **al menos cuatro algoritmos de ordenamiento** diferentes.
- Comprender y aplicar la **notación Big O** para evaluar la complejidad temporal de un algoritmo.
- Elegir el algoritmo más eficiente según el tipo de entrada.
- Conocer la diferencia entre algoritmos **estables** e **inestables**.

---

## 📋 Requisitos del proyecto

- **Editores permitidos:** `vi`, `vim`, `emacs`.
- **Compilación:** Ubuntu 20.04 con `gcc`, usando las opciones:
  `-Wall -Werror -Wextra -pedantic -std=gnu89`
- **Estilo de código:** debe seguir las normas **Betty**.
- No se permite el uso de **variables globales**.
- Máximo **5 funciones por archivo**.
- No se permite el uso de funciones de la **librería estándar** como `printf`, `puts`, etc.
- Los **archivos de prueba (`main.c`)** son solo para uso personal. No serán evaluados.
- Todos los **prototipos** deben estar en un archivo de cabecera llamado `sort.h`.
- Todos los **header files** deben tener **include guards**.
- No es necesario ordenar una lista/arreglo si su tamaño es menor a 2.

---

## 🧠 Algoritmos implementados

- **Bubble Sort**
- **Insertion Sort**
- **Selection Sort**
- **Quick Sort**
- *(opcional: se pueden agregar otros como Merge Sort, Heap Sort, Shell Sort, etc.)*
